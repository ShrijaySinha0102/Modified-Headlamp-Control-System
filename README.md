•	Designed and implemented a modified car headlight system using Verilog to create an energy-saving logic.
•	The core implementation includes a timer that automatically turns off the headlight after a 10-second delay if the ignition is off and the light switch is left on. This simple mechanism significantly reduces battery consumption by preventing accidental power drain.
•	The primary operational logic allows the headlight to be operated via a switch only when the vehicle ignition is active.
